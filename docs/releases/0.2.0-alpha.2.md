# LoopForge 0.2.0-alpha.2 — Native Studio UI

This Windows x64 test build includes the standalone EXE and VST3 with the updated black-and-lime studio interface. The left panel groups musical direction, seed and generation. The right panel keeps transport, MIDI export and the piano roll or loop overview together. The piano roll has a fixed bar ruler, clearer piano keys and a brighter active track.

For offline generation, launch the EXE, enter a direction such as `8 bars D minor 104 bpm ambient bass chords melody drums` and click **Compose Loop**. Use **Play / Stop** and **Sound** for the basic preview, **Show Overview** to switch from the piano roll to the track overview, and **Export MIDI** to move the loop into FL Studio. New native loops remain limited to 16 bars. Existing project and recipe files retain their format.

Extract the whole ZIP. See `FL-STUDIO-TEST.md` for the VST3 installation and routing steps. This alpha is unsigned. Windows compilation and automated verification accompany the build. Loading and playing it in FL Studio still requires a host test.
