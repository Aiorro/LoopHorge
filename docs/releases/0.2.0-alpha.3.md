# LoopForge 0.2.0-alpha.3 — Signal console

The native Standalone and VST3 use a full-width instrument console. Direction, seed, offline composition and preview are together above the MIDI signal map. The map displays the active project's tempo, track activity and note-on velocities. The piano roll and track overview now use the full width of the window. Click a track in the signal display to edit it in the piano roll. Track colours carry across both views.

Start with **Compose Loop** for a 4, 8 or 16-bar offline composition. Use **Idea Settings** for provider, model and generation settings in the idea bank. Use **Mood Settings** for seven Auto/manual rotary controls. Use **Export MIDI** to move the loop into your DAW.

The Windows x64 ZIP includes a native EXE, VST3, source archives and license notices. Extract the whole ZIP and follow `FL-STUDIO-TEST.md` for host installation and routing. The build is unsigned. FL Studio host acceptance remains open.
