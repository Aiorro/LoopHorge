# LoopForge 0.2.0-alpha.4 — Local MIDI-LLM preview

Extract the Windows x64 ZIP and launch Standalone. **Model Setup** opens the local setup wizard from the extracted package. You can also run `MIDI-LLM/Setup MIDI-LLM.cmd` directly. Use 64-bit Python 3.11 or 3.12. The wizard reports RAM, free disk space and NVIDIA VRAM, then offers an isolated runtime and model download after you review the license. The published model weighs about 2.8 GB. Dependencies require additional space.

**MIDI-LLM** becomes the initial engine when a local setup is registered. **Rule Composer** remains available. Describe a genre or musical direction and choose a 4, 8 or 16-bar loop. The model's instrument programs and drum channel are retained in exported MIDI. Built-in preview has original program-aware tones for keys, bass, plucks, pads, leads and percussion.

Built with Llama 3.2. The model and its license are available from the [publisher](https://huggingface.co/slseanwu/MIDI-LLM_Llama-3.2-1B). Download and inference performance depend on the machine. Windows host playback and first-run model download still require manual acceptance.
