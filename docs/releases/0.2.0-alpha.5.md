# LoopForge 0.2.0-alpha.5 test candidate

This candidate uses commit `d3df8eeb29a4beb3c3777b36ba330606b77705bb`. The packages contain Standalone and VST3 for x64. Rule Composer generates 4, 8 or 16-bar loops and works offline without a model or Node.js. The application reports the base version 0.2.0.

## Changes since alpha.4

- The native editor and web composer use the updated compact layout with a full-width piano roll and teal-to-lime accents.
- Rule Composer supports track-specific bar regeneration against the committed harmony. Undo restores the previous notes.
- The native player releases active notes and pedals on bypass in the automated processor checks.
- Project, recipe and MIDI file I/O runs in the background. A delayed project load cannot replace a newer committed revision.
- English and Russian cello directions select General MIDI Program Change 42 on the lead track. Rule Composer recognizes `трап`. The legacy generation API reports unsupported genre choices.
- The browser uses the same selected idea for the MIDI data and the download filename.

## Windows test package

1. Download and extract the [Windows Actions artifact](https://github.com/Aiorro/LoopHorge/actions/runs/45123203349/artifacts/14794384015). Check the outer artifact ZIP against SHA256 `e53db68a54945ba8893da6505684dc0799f84ef52f591aae78996c2d0994285b`.
2. The artifact contains `LoopForge-0.2.0-windows-x64-d3df8eeb29a4-candidate.zip` and `SHA256SUMS`. The verified inner ZIP SHA256 is `3feaa279c5d25384d28378da614174b9a73a6f86f6c84e339b1bac6a8eab3e77`. Compare the inner ZIP hash with that file using `Get-FileHash -Algorithm SHA256 -LiteralPath '<candidate.zip>'`. Extract the inner ZIP after the hashes match.
3. Start `Standalone/LoopForge AI MIDI.exe` or copy the complete `VST3/LoopForge AI MIDI.vst3` bundle into the Windows VST3 directory. Scan in FL Studio and follow the included `FL-STUDIO-TEST.md`. To remove the test build, close the host and remove the copied bundle and the extracted package.
4. In Rule Composer, enter `16 bars D minor 120 bpm trap bass piano cello drums` with seed `42`. Generate, audition, change a track region, undo, save and reopen the project, and export the Type-1 MIDI for import in the DAW. With a receiving VST instrument, turn off Sound and match the wrapper MIDI output and input ports.

The existing archive contains alpha.4 notes under `RELEASE-NOTES.md`. Use these alpha.5 notes for the changes and test scope of the candidate above.
