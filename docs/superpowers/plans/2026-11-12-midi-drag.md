Spec: docs/superpowers/specs/2026-11-12-midi-drag-design.md.

## Task1 cache

Create Source/DragMidi.h and tests/DragMidiTest.cpp; register drag_midi_test. Interfaces: DragMidiCache(root).prepare(idea,nowMs) -> Result {shared_ptr<DragMidiLease> lease; String error}; lease.file remains on disk after destruction. A short per-root InterProcessLock serializes prepare/prune/quota checks. Native thread-independent read leases deny deletion on Windows and use flock on POSIX; expiry cleanup attempts an exclusive lease and skips active files. Create UUID files exclusively. Only recognized regular non-symlink UUID.mid files may be pruned; cache path symlinks rejected. Tests first: actual MIDI decode, invalid input/no files, missing/unwritable root,256file/16MiB cap, age pruning, unknown/symlink preservation and active file retention across callback threads. Observe missing-interface failure, implement, build/run test and existing suites.
